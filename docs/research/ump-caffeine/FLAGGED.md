# UMP + caffeine research model: flagged items

Items the sources read do not settle. None is guessed. Each is either left unimplemented (throws or has no API) or the choice is stated here with its consequence.

| ID | Item | What the papers say | What the code does |
|---|---|---|---|
| F1 | Clock origin of t in C(t) = Σ aᵢ sin(i·2π(t + φ)/τ) | 2013, 2014, 2016a, 2016b and 2023 all write t + φ and never state what t = 0 is (midnight, start of study, first wake). 2014 calls φ the "initial circadian phase" in a discrete-time form starting at the first sample, which suggests a study-relative origin, but no paper states it for the UMP. | No clock-time or Date API. Callers give the schedule in model hours from t = 0. Mapping t to local time is unimplemented. Aurora's earlier review (docs/research/energy-model.md §4.2) argued that a clock-hour reading conflicts with the authors' own simulation descriptions; that is an inference and is not used here. |
| F2 | Repeated caffeine doses | 2016b Table 2 footnote: "Refer to Ramakrishnan et al. [2014] for details regarding model extension for repeated caffeine doses." 2014 Eqs 6–8 extend the gPD form **without absorption** (gPD = [1 + MD·e^(−kD·t)]⁻¹) using an equivalent extant dose E(tj). How ka enters E(tj) and the multi-dose gPD in the 2016b absorption form is not given in any source read. Vital-Lopez 2018 puts its equations in Supporting Information, which was not available. | More than one dose throws `repeatedDosesNotPublished`. |
| F3 | ka for coffee, tea, energy drinks | Only capsule (2.06 h⁻¹) and gum (3.21 h⁻¹) are published (2016b Table 3). 2014 p. 13 says absorption from coffee, tea, energy drinks and most gums is much faster than elimination (by a factor over 15) but gives no rate. | Only `.capsule` and `.gum` exist. |
| F4 | S during sleep once L reaches its floor | 2016b Eq 4's closed form uses the unclamped L trajectory. The defining ODE (2016a Table 2 Eq 3; 2023 Table 2 Eq 4) uses L(t) from Eq 5, which includes the max(·, −0.11U) floor. The two agree until L reaches the floor. | Follows the ODE: Eq 4 until L hits −0.11U, then S relaxes to the floor with τs. Size of the difference with the lapse set from S0 = 0.5, L0 = 0: L reaches the floor 9.50 h into a sleep; at 10, 12 and 14 h of sleep, printed Eq 4 gives S lower by 0.011, 0.213 and 0.542 lapses. Which form the authors' own software uses is not published. |
| F5 | Parity against published curves | Every model curve in 2013, 2014, 2016a, 2016b and 2023 is a figure. No table of predicted values exists in the sources read. | No curve parity. Figures were not digitized. Tests check only the numbers the papers state in text. |
| F6 | 2016a's reported initial state | 2016a p. 251 says S and L at the end of the training study's baseline (3 nights of 8 h TIB, 07:00 wake) "were computed to be 0.50 and 0.00 lapses", from the fitted S0 = 0.00 and L0 = −4.96 (p. 253). Simulating that with the 2016a fit (U = 18.35, τw = 40.00, τs = 2.11, τLA = 7.00 d), with or without the floor, from either a wake or sleep start, did not give 0.50 / 0.00. L0 = −4.96 is also below the −0.11U floor the same paper introduces. | Not reproduced, not used as a test. The model starts from 2016b Table 3's S0 = 0.5 and L0 = 0.0 as published. |
| F7 | Rajdev 2013 Fig 1 debt values | Text says Debt ≈ 0.557 after 7 days of 3 h TIB and ≈ 0.452 after 64 h TSD, but Fig 1's τLA and starting debt are not stated. No single stated τLA (4.06 d, 120 h, 7 d) reproduces both from zero debt. | Not used as a test. |
| F8 | "Magnitude 0.06 U" of the 8 h TIB oscillation (2013 p. 69, τLA = 120 h) | One significant figure; "magnitude" is not defined. | Half peak-to-peak computes to ≈ 0.066. The test accepts 0.06 ± 0.01 and says so; it is a consistency check, not precise parity. |
| F9 | Prediction intervals | 2016b Eq 7 needs σp and σm; no values are printed. | Not implemented. |
