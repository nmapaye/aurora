Aurora Support

Last updated: July 9, 2026

Getting Help

For beta and release support, open an issue on the Aurora GitHub project or use the support link provided in the App Store listing or Gumroad companion guide.

GitHub: github.com/nmapaye/aurora/issues

Before Reporting

  • Include the Aurora version, iOS version, and device model.
  • Note whether Health access was granted, denied, or unavailable.
  • Do not include private Health data in public issue reports.

Known Limits

Aurora v0.1.0 is iOS-first. Android health integration, cloud sync, Apple Watch support, and background automation are deferred.
